1.2 · Qué hace cada parte
Parte Qué hace
action  y method La página que recibe los datos y cómo viajan. Con get  se ven en la barra
de direcciones
<label for>  + id Unen la etiqueta con su campo: al hacer clic en el texto, el cursor salta al
campo, y el lector de pantalla lo anuncia
name El nombre con que viaja cada dato. Un campo sin name  no se envía
type text , email , tel  y checkbox  cambian el teclado del celular, la forma del
campo y lo que se valida
required Campo obligatorio: el formulario no se envía si está vacío
minlength  y
maxlength
Cantidad mínima y máxima de caracteres
pattern  + title Una regla propia (aquí, nueve dígitos) y el texto que explica qué se espera
<fieldset>  +
<legend>
Agrupan campos relacionados y les ponen un título
<select> Lista desplegable. La primera opción, con value  vacío, obliga a elegir
<button> submit  envía, reset  limpia. En el Paso 6 usarás type="button"  para los
controles del video
Comprueba: pulsa «Enviar mensaje» con el formulario vacío: aparece un aviso en el primer campo
y no se envía. Complétalo y envíalo: la dirección cambia a contactame.html?nombre=…&correo=… ,
con un par name=valor  por cada campo.
A dónde llegan los datos: a ningún lado, todavía. Tu sitio es estático: no hay un programa que
reciba el mensaje. Con method="get"  puedes ver en la dirección que cada campo viaja con
su name , y eso es lo que evaluamos hoy.
Sobre el aspecto: el formulario se ve con el estilo básico del navegador. En la sesión 08 le
das el aspecto de tu diseño con CSS.

3.1 · Exporta en MP4 y en WebM

function formatearTiempo(segundos) {
  const minutos = Math.floor(segundos / 60);
  const resto = Math.floor(segundos % 60);
  return minutos + ":" + String(resto).padStart(2, "0");
}
function actualizarAvance() {
  const duracion = video.duration || 0;
  barra.max = duracion;
  barra.value = video.currentTime;

Paso 7 · El iframe de YouTube, limpio
El código que entrega YouTube funciona, pero trae cosas que conviene corregir. Déjalo así:
<figure>
  <iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/TNhX1uR2vO8"
    title="Reproductor de video de YouTube"
    loading="lazy"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-
in-picture; web-share"
    referrerpolicy="strict-origin-when-cross-origin"
    allowfullscreen
  ></iframe>
  <figcaption>Video alojado en YouTube.</figcaption>
</figure>
Se quita frameborder="0" : es un atributo obsoleto y el validador W3C lo marca como error. El
borde se quita con CSS en la sesión 08.
Se quita el texto «Tu navegador no soporta…» que estaba dentro: lo que se escribe entre
<iframe>  y </iframe>  nunca se muestra.
Se quita ?si=…  del final de la dirección: es un código de seguimiento que no hace falta.
Se añade loading="lazy" : el reproductor no se carga hasta que la persona se acerca a él.
El title  describe el contenido para quien usa lector de pantalla.
