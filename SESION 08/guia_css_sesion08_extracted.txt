Regla de oro del curso: organiza siempre tus estilos en archivos según su función. No
coloques todo el código en un único archivo gigante ni uses atributos style="..."  dentro de
las etiquetas HTML.
Idea clave antes de empezar
En un entorno web profesional los estilos se modularizan: lo global (colores y tipografías) vive en
global.css , los componentes repetidos (menú y pie) viven en header.css , y lo exclusivo de
cada página va en su propio archivo. Así, cada página carga exactamente lo que necesita.

2.2 · Declara los tokens de Figma como variables en :root
Un token es un valor que se repite en todo el diseño. En Figma los encuentras en las secciones
Relleno (colores), Tipografía (fuentes) y Radio de esquina de cualquier capa: el #06B6C4  del
botón azul, el #E5E7EB  de todos los trazos, el radio 8  de los botones y el 12  de las tarjetas.
/* 2. Tokens de Figma como variables CSS */
:root {
  --color-primary: #06B6C4;        /* Azul / Cyan de Figma para botones y acentos */
  --color-bg: #F9FAFB;             /* Fondo neutro de la página web */
  --color-surface: #FFFFFF;        /* Fondo de cabecera y tarjetas */
  --color-text-primary: #0B0F19;   /* Títulos y textos principales */
  --color-text-secondary: #374151; /* Párrafos descriptivos */
  --color-text-muted: #9CA3AF;     /* Enlaces de menú en reposo */
  --color-border: #E5E7EB;         /* Bordes sutiles */
  --font-heading: 'Outfit', sans-serif;
  --font-body: 'Geist', sans-serif;
  --font-code: 'Geist Mono', monospace;
  --radius-sm: 8px;
  --radius-md: 12px;
}
Por qué usar variables CSS si en el futuro decides cambiar el color principal de la marca,
solo modificas el valor de --color-primary  en una línea y todo el sitio web se actualiza
automáticamente.

2.3 · Reset universal y estilos base
Al final de global.css , añade las reglas base para eliminar los márgenes que trae el navegador y
aplicar la tipografía a toda la web:
/* 3. Reset universal del modelo de caja */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
/* 4. Configuración general del cuerpo del documento */
body {
  background-color: var(--color-bg);
  color: var(--color-text-secondary);
  font-family: var(--font-body);
  font-size: 16px;
  line-height: 1.6;
}
/* 5. Títulos con la fuente geométrica de Figma */
h1, h2, h3, h4 {
  font-family: var(--font-heading);
  color: var(--color-text-primary);
  line-height: 1.2;
}
/* 6. Enlaces limpios sin subrayado automático */
a {
  text-decoration: none;
  color: inherit;
}
/* 7. Listas sin viñetas por defecto */
ul {
  list-style: none;
}
¿Por qué usamos box-sizing: border-box? Esta regla asegura que el padding  y los bordes
que añadas a cualquier caja se calculen dentro del ancho total, evitando desbordes
horizontales imprevistos.

7.5 · Adaptación para móviles y tablets
Al final de index.css , añade las media queries para que las columnas se apilen en pantallas
estrechas:
/* 5. Adaptación responsiva para móviles y tablets */
@media (max-width: 992px) {
  .hero-section {
    flex-direction: column;
    padding: 60px 24px;
    text-align: center;
  }
  .hero-actions { justify-content: center; }
  .hero-right { width: 100%; }
  .code-body {
    text-align: left;   /* el código no hereda el centrado del hero */
    overflow-x: auto;   /* si una línea no cabe, se desplaza dentro de la tarjeta */
  }
}
@media (max-width: 600px) {
  .hero-title { font-size: 40px; }
}
Herencia en acción: al centrar el Hero con text-align: center , el código de la tarjeta
también se centraría, porque text-align  se hereda. Por eso .code-body  vuelve a pedir
text-align: left .
