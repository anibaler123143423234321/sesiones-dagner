# USS - Sesiones y Materiales Académicos

Repositorio con el contenido de las sesiones de clase, recursos, libros y materiales académicos correspondientes a la Universidad Señor de Sipán (USS).

---

## 📁 Estructura del Repositorio

- **`ASISTENCIAS/`**: Registros y listas de control de asistencia.
- **`ELLUCIAN/`**: Diapositivas e instructivos sobre el sistema Banner/Ellucian (periodos académicos, asignaturas, docentes, admisión).
- **`LIBROS/`**: Bibliografía y manuales de referencia (HTML5, CSS3, JavaScript).
- **`RECURSOS/`**: Archivos base, guías y recursos de trabajo para las clases.
- **`SESION 01 - 16/`**: Diapositivas, guías prácticas, actividades, portafolios y tareas desarrolladas sesión a sesión.
  La sesión 08 (jueves 8 de octubre) fue feriado: sus contenidos se reparten entre las sesiones 09 y 10.
  La sesión 12 incluye el Taller online TA2 (15 %), en `SESION 12/Taller online [TA2].docx` y `.pdf`.
  Las sesiones 13 y 14 añaden al portafolio la página `cursos.html`, hecha con Bootstrap 5.3.
  Las sesiones 11 a 15 tienen un extra de IA: una guía con buenos prompts para el código y las funciones de IA de Figma.
  La sesión 15 cierra el proyecto integrador: pruebas, `<head>` completo, página 404, Netlify Forms y Lighthouse.
  `SESION 15/figma-portafolio-completo/` muestra el diseño terminado en Figma, con el enlace al archivo.
  La sesión 16 es el examen final (30 %): el cuestionario en el Aula Virtual y la presentación del proyecto integrador.
  `SESION 16/docente/` guarda la clave del cuestionario, el banco para Moodle y la planilla de calificación: solo para el docente.
- **`FUENTES/`**: Scripts que generan las diapositivas, las guías, los cuestionarios, el TA2 y el examen final (ver `FUENTES/sesiones-09-16/LEEME.md`).
