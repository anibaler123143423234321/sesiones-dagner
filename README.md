# USS - Sesiones y Materiales Académicos

Repositorio con el contenido de las sesiones de clase, recursos, libros y materiales académicos correspondientes a la Universidad Señor de Sipán (USS).

---

## 📁 Estructura del Repositorio

- **`ASISTENCIAS/`**: Registros y listas de control de asistencia.
- **`ELLUCIAN/`**: Diapositivas e instructivos sobre el sistema Banner/Ellucian (periodos académicos, asignaturas, docentes, admisión).
- **`LIBROS/`**: Bibliografía y manuales de referencia (HTML5, CSS3, JavaScript).
- **`RECURSOS/`**: Archivos base, guías y recursos de trabajo para las clases.
- **`SESION 01 - 10/`**: Diapositivas, guías prácticas, actividades, portafolios y tareas desarrolladas sesión a sesión.
  La sesión 08 (jueves 8 de octubre) fue feriado: sus contenidos se reparten entre las sesiones 09 y 10.
- **`FUENTES/`**: Scripts que generan las diapositivas, las guías y los cuestionarios (ver `FUENTES/sesiones-09-10/LEEME.md`).
